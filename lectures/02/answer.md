- 学習前：`format_rate` = 対象外 / `content_rate` = 未算出
  今回は自由文回答を学習したため、公式演習のJSON形式遵守率は測定していない。回答内容は定性的に比較した。

- 学習後：`format_rate` = 対象外 / `content_rate` = 未算出
  学習後も同じ生成条件で評価したが、厳密な正解率の自動採点は実施していない。

- 退行した質問：
  正誤ラベルによる学習前後の自動採点は行っていないため、退行件数は未判定。言い換え質問では、学習後にも不正確な説明が残った。

- 学習後に残った失敗と、その型（根拠なしの質問に断定した / 根拠ありの質問に確認要求で逃げた / 形式の崩れ）：
  用語集にない架空用語3問に対して、学習後もすべて根拠のない説明を生成した。また、既知用語でもLoRAの仕組みに不正確な説明があり、「APIキーを公開する」という誤った記述も見られた。今回はJSON形式を要求していないため、形式の崩れは評価対象外とした。

- 知識を問う質問（セクション 6）の結果（学習前の分類 → 学習後の分類）と気づいたこと：

- 学習で変わったこと・変わらなかったこと：
  Training Lossはステップ10の3.205689からステップ40の1.364306まで低下した。既知用語「ハルシネーション」の直接質問などでは説明が改善したが、言い換えへの対応や未知用語への慎重な判断は十分に改善しなかった。

## 宿題

- 取り組んだレベル：発展

- 変えた設定やデータ：
  `scripts/make_sft_dataset.py` で講座用語集58語から116件のQ&AデータをJSONL形式で生成した。各用語の1問目58件を学習用、2問目58件を検証用とし、5エポック学習した。評価では既知の3用語について学習時と同じ質問3問・言い換え3問に加え、用語集にない架空用語3問を用意した。さらに用語集の定義を返す簡易文字列検索を実装し、同じ9問で比較した。

- 結果（比較表や数字）：
  学習対象パラメータは6,389,760 / 758,782,784（0.8421%）、学習時間104.4秒、40ステップ、最終記録Lossは1.364306だった。

  | 評価項目 | LoRA学習後 | 簡易用語集検索 |
  | --- | --- | --- |
  | 既知用語6問 | 一部改善したが不正確な回答が残った | 6問で登録済み定義を返した |
  | 未知用語3問 | 3問とも根拠のない説明を生成 | 3問とも確認が必要と回答 |

  検索方式は今回の9問すべてで期待動作と一致した。ただし9/9は検索方式の結果であり、LoRAの正解率ではない。学習前・学習後・検索方式の回答全文は `glossary_evaluation.json` に保存した。

- ファインチューニングが向く場面・向かない場面についての考察：
  LoRAはモデル全体を更新せず、少ない学習対象パラメータで回答傾向や文体を調整する用途に向く。しかし今回、損失が下がっても定義を正確に再現できるとは限らず、未知用語へのハルシネーションも残った。正確な根拠が必要な質問や、情報更新が多い場面では、外部データを検索して参照する方式が適していると考える。一方、今回の検索方式は単純な文字列一致であり、表記ゆれや曖昧な質問への対応には限界がある。また、検証データは学習用と同じ58語の言い換えなので、未学習用語への汎化性能を示すものではない。今後は未学習語を分離したテストと統一した採点基準で比較したい。
